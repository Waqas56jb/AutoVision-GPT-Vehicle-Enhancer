# Manufacturer logos (optional)

Drop an official manufacturer logo here to have it appear in the marketing tag
instead of the typographic fallback (the maker's initial on an accent tile).

- Name the file after the brand key, lowercase: `honda.png`, `toyota.png`,
  `mazda.png`, `hyundai.png`, `kia.png`, `subaru.png`, `nissan.png`, `mg.png`,
  `ford.png`, `bmw.png`, `mercedes.png`, `audi.png`, `volkswagen.png`, etc.
  (The keys are the ones in `src/config/brands.js`.)
- PNG with transparency works best. SVG, JPG and WEBP are also accepted.
- Roughly square, with a little padding, looks best in both the corner tag and
  the header/footer bands.

These are the dealer's own brand assets, used to market the vehicles they sell.
The application ships no manufacturer artwork itself — without a file here the
tag uses a clean typographic badge in the brand's accent colour.
